## 🗂️ What's in Here

| Category | What you'll find |
|---|---|
| **Lecture Notes** | Slides and notes (PDF), per course |
| **Lab Materials** | For courses with a lab component — manuals, reports, templates (nested inside the parent course folder) |
| **Past Papers** | Quizzes, midterms, finals, where available |
| **Solved Problems** | Worked examples and practice sets |
| **Exam Prep** | Summaries, formula sheets, quick-reference notes |
| **Resources** | Curated Google Drive folders and YouTube playlists — linked, not duplicated |
| **Projects** | For courses with a term project |

Not every course has every category — it depends on how the course is actually taught. Each course folder's exact internal layout may vary slightly to fit that course.

## 🏗️ Repository Structure

Courses sit directly at the repo root. Each course is fully self-contained, and `QUICK-INDEX.md` gives a quick table of every course with a direct link to its folder.

```
BRACU-EEE-Vault/
├── README.md
├── LICENSE
├── QUICK-INDEX.md         → table of all courses with quick links
├── TEMPLATES/             → reusable file/folder templates
├── RESOURCES/             → shared across all courses (curriculum PDF, general study tips)
├── EEE101/
│   ├── README.md
│   ├── (internal structure defined per-course)
│   └── EEE101 LAB/        → lab component, nested inside the parent course
├── EEE103/
│   ├── README.md
│   └── EEE103 LAB/
├── MAT120/
├── STA201/
└── ...                    (more courses added over time)
```

> Each course's exact internal folder layout is defined and maintained on a course-by-course basis — see that course's own README for specifics.

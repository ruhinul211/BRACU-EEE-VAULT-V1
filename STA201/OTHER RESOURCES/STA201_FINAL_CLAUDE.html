Lecture 10 — Probability Fundamentals

What is Probability, Really?

Probability is just a number between 0 and 1 that tells you how likely something is to happen. 0 means "impossible," 1 means "certain," and everything in between is a shade of "maybe." You can write it as a fraction (like \(\frac{1}{6}\)), a decimal (0.1667), or a percentage (16.67%) — they're all the same idea.

The Vocabulary You Need First

Before any formula makes sense, you need five words locked in. Think of a vending machine as the running example.

Experiment — any process you repeat under the same conditions, where you can list the possible results in advance, but can't say for certain which one will happen this time. Pressing a button on the vending machine and seeing what drops out is an experiment — every time you press it, one of a known set of things happens, but you don't know which until it happens.
Trial — one single instance of running the experiment. One button-press is one trial.
Outcome — one possible result of a single trial. "A cola drops out" is one outcome.
Sample Space (S) — the set of ALL possible outcomes. If the machine only stocks cola, juice, and water, then \(S = \{\text{cola}, \text{juice}, \text{water}\}\).
Event — any subset of the sample space — that is, any collection of outcomes you've decided to group together and call "interesting." "Getting a drink that isn't water" is the event \(E = \{\text{cola}, \text{juice}\}\).
🎓 Professor's Thought

The single most common exam slip is mixing up "outcome" and "event." An outcome is atomic — you can't break it down further (rolling a "4"). An event can be a single outcome OR a bundle of them ("rolling an even number" = {2,4,6}). When a question says "find the probability of event E," always write out what E actually contains before you touch a formula — half of all classwork errors come from skipping this step.

Deterministic vs. Random Experiments

An experiment is deterministic if the outcome is guaranteed once you know the starting conditions — like calculating compound interest from a known deposit and rate. Nobody needs probability for that; it's just arithmetic. An experiment is random (or unpredictable) if you cannot know the outcome in advance even though you know all the possible outcomes — tossing a coin, rolling a die, drawing a card. STA201, and probability theory generally, only cares about random experiments.

Types of Events

These four properties come up constantly, and questions often ask you to identify which one applies — so keep them separated in your head as different questions, not different flavors of the same idea:

Mutually Exclusive — two events can't both happen in the same trial. Getting Heads and getting Tails on one coin toss can't happen together, so they're mutually exclusive. Test: does \(A \cap B = \emptyset\) (no shared outcomes)?
Collectively Exhaustive — together, the events cover every possible outcome in S, leaving nothing out. Heads and Tails together ARE collectively exhaustive for a coin toss (nothing else can happen).
Equally Likely — each outcome has the same probability of occurring as every other. Each face of a fair die has probability \(\frac{1}{6}\) — equally likely.
Disjoint — same meaning as mutually exclusive: zero elements in common. (Note: "mutually exclusive" and "disjoint" are literally the same test — different textbooks just use different words for it.)
Dependent / Joint Events — events that DO share common outcomes. Drawing a "Red card" and drawing a "Queen" from a deck share outcomes (Queen of Hearts, Queen of Diamonds are both red AND queens), so they are not mutually exclusive — they're joint/dependent in the set-theory sense used here.
🎓 Professor's Thought

Careful: "dependent" here means "share outcomes" (a set-theory idea), which is a DIFFERENT concept from statistical independence (a probability idea, covered next). A question can have events that share no outcomes (mutually exclusive) yet are NOT independent in the probability sense, and vice versa. Don't let the similar-sounding words trick you into treating them as the same test.

Set Operations You'll Use Constantly

Since events are just sets of outcomes, the three basic set operations translate directly into probability language:

  • Union \(A \cup B\) — outcomes in A, or B, or both. In plain English: "A or B happens."
  • Intersection \(A \cap B\) — outcomes in both A and B. Plain English: "A and B both happen."
  • Complement \(A^c\) or \(A'\) — everything NOT in A. Plain English: "A does not happen."

Independent Events

Two events are independent if knowing that one happened tells you nothing new about whether the other will happen. Formally, for independent A and B:

\[P(A \cap B) = P(A) \cdot P(B)\]

Coin tosses are the classic example: the coin has no memory, so what happened on toss 1 has zero bearing on toss 2.

Two Ways to Assign a Probability Number

Classical Approach — used when outcomes are equally likely. Just count:
\[P(A) = \frac{n(A)}{n(S)} = \frac{\text{number of outcomes favorable to } A}{\text{total number of outcomes}}\]
Frequency (Empirical) Approach — used when outcomes are NOT equally likely and you have to rely on repeated observation instead. Run the experiment n times, count how often A occurs (call it f), and as n grows huge:
\[P(A) = \lim_{n\to\infty}\frac{f}{n}\]
In practice on an exam, you're just given a large-sample relative frequency and treat it as the probability.
Worked Example

In a dice-throwing experiment, 2 occurred 998 times out of 6000 trials. Find P(getting a 2) using the frequency approach.

Solution: \(P(A) = \frac{998}{6000} \approx 0.1663 \approx \frac{1}{6}\) — consistent with the classical probability we'd expect from a fair die.

The Three Axioms of Probability

Everything in probability theory is built on three rules that any valid probability assignment must obey:

Axiom 1 (Positivity): \(0 \le P(A) \le 1\) for every event A — never negative, never above 1.

Axiom 2 (Certainty): \(P(S) = 1\) — something in the sample space always happens.

Axiom 3 (Additivity): for disjoint events \(A_1, A_2, \ldots, A_n\): \[P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)\]
Worked Example

A person holds a ticket in a lottery offering 10 prizes out of 120 tickets sold. What is the probability the person will NOT win a prize?

Solution: Let A = winning a prize. \(P(A) = \frac{10}{120} = \frac{1}{12}\). Using the complement rule, \(P(A') = 1 - \frac{1}{12} = \frac{11}{12}\).

Answer: 11/12 ≈ 0.9167

The Addition Law (a.k.a. "OR" probability)

This is one of the most exam-tested formulas in the whole course. There are two versions depending on whether the events overlap:

If A and B are mutually exclusive (disjoint): \[P(A \cup B) = P(A) + P(B)\] If A and B overlap (joint): \[P(A \cup B) = P(A) + P(B) - P(A \cap B)\] For three overlapping events A, B, C: \[P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(A\cap B)-P(B\cap C)-P(A\cap C)+P(A\cap B\cap C)\]
🎓 Professor's Thought

Why subtract \(P(A \cap B)\)? Because if you just add \(P(A) + P(B)\), you have counted the overlap region TWICE — once inside A, once inside B. Subtracting it once brings it back to being counted exactly once. This "add, then correct for double-counting" logic is exactly why the three-event formula has a plus at the very end — the triple-overlap region gets subtracted three times (once per pair) and added back once. If you understand this Venn-diagram intuition, you never need to memorize the three-event formula — you can rebuild it from scratch under exam pressure.

Expanded Concept — Combinatorics Primer (nCr, "n choose r")

You will not survive the Binomial distribution (Lecture 15-16) without this. It quietly underlies every "how many ways can this happen" question in the course, even though the slides never dedicate a section to it.

Factorial (n!) — the product of all positive integers up to n. \(5! = 5\times4\times3\times2\times1=120\). Special case: \(0!=1\) (defined this way so formulas work cleanly at the boundary).
\[\binom{n}{r} = \frac{n!}{r!(n-r)!}\]

Read \(\binom{n}{r}\) as "n choose r" — the number of ways to select r items out of n total items, where the ORDER you pick them in doesn't matter.

Worked Example

In how many ways can you choose 2 students from a group of 5 to form a committee?

Solution: \(\binom{5}{2}=\frac{5!}{2!3!}=\frac{120}{2\times6}=10\)

Answer: 10 ways
🎓 Professor's Thought

In the Binomial formula \(\binom{n}{x}p^xq^{n-x}\), the \(\binom{n}{x}\) term exists because there are MULTIPLE different orderings of successes and failures that all give you the same total count x — for example, getting 2 heads in 3 tosses could happen as HHT, HTH, or THH. Each individual ordering has probability \(p^2q^1\), but since there are \(\binom{3}{2}=3\) different orderings that all count as "2 heads," you multiply by 3. This is the single most important intuition for understanding WHY the binomial coefficient belongs in the formula at all — it's not just decoration, it's counting the number of equally-likely arrangements.

Worked Example

60% of employees have a motorcycle, 40% have a private car, 20% have both. Find (a) P(motorcycle or car), (b) P(neither).

Solution: Let M = motorcycle, C = car. \(P(M)=0.6, P(C)=0.4, P(M\cap C)=0.2\).
(a) \(P(M\cup C) = 0.6+0.4-0.2 = 0.8\)
(b) \(P((M\cup C)^c) = 1-0.8 = 0.2\)

Answers: (a) 0.8 (b) 0.2

Lecture 11 — Conditional Probability & Bayes' Theorem

The Core Idea: Probability After News Arrives

Conditional probability answers one question: "Given that I now know B happened, how likely is A?" Learning that B happened shrinks your sample space down to just the outcomes where B is true — you're no longer looking at the whole universe S, you're only looking inside B. The formula:

\[P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0\]

Read the bar "|" as "given." \(P(A \mid B)\) = "the probability of A, given that B has already happened."

🎓 Professor's Thought

Picture it as zooming in. Before any information, your sample space is all of S. Once you're told "B happened," your entire world shrinks to just the B-shaped region — and now you ask what fraction of THAT smaller region is also A. That's exactly what dividing by P(B) does: it rescales the "both A and B" sliver so it's a fraction of B alone, not a fraction of the whole original S.

The Product Rule (Law of Multiplication)

Just rearrange the conditional probability formula and you get a way to compute joint (AND) probabilities:

For dependent events: \[P(A \cap B) = P(A\mid B)\,P(B) = P(B\mid A)\,P(A)\] For independent events (recall Lecture 10): \[P(A \cap B) = P(A)\,P(B)\] For three events: \[P(A \cap B \cap C) = P(A)\,P(B\mid A)\,P(C \mid A \cap B)\]
Worked Example

In a class of 120 students: 60 study English, 50 study French, 20 study both. Find P(studying English | studying French).

Solution: \(P(E)=\frac{60}{120}=0.5\), \(P(F)=\frac{50}{120}\approx0.417\), \(P(E\cap F)=\frac{20}{120}\approx0.167\).
\(P(E\mid F) = \frac{P(E\cap F)}{P(F)} = \frac{20}{50} = 0.4\)

Answer: 0.4
🎓 Professor's Thought

Notice the shortcut in the worked example: instead of dividing the decimals 0.167/0.417, we went straight to 20/50 using the raw counts. Whenever a problem gives you frequency-table-style counts, skip converting to probabilities first — divide the intersection COUNT by the condition COUNT directly. It's faster and avoids rounding errors, which examiners specifically check for.

Probability Using Contingency (Two-Way) Tables

A contingency table cross-tabulates two categorical variables. Every classwork/exam question with a table like this reduces to reading off the right cell and the right row/column total:

Y₁Y₂Total
X₁aba+b
X₂cdc+d
Totala+cb+da+b+c+d

To find, say, \(P(X_1 \mid Y_1)\): take the cell a (both X₁ and Y₁) divided by the column total a+c (all of Y₁). The condition given always tells you which row or column total to divide by.

🎓 Professor's Thought

The single fastest way to avoid contingency-table mistakes: whatever comes AFTER the word "given" in the question is your denominator — and it must be the ROW or COLUMN TOTAL, never the grand total, unless the question asks for an unconditional (marginal) probability with no "given" at all.

Tree Diagrams for Conditional Probability

A probability tree is just a visual way to chain conditional probabilities. Steps:

  1. Decide if events are dependent or independent.
  2. Draw first-level branches for the first event's outcomes, with their probabilities on each branch.
  3. From each first-level branch, draw second-level branches for the next event, using the CONDITIONAL probability given that first branch.
  4. To get the probability of a whole PATH (a full A-then-B outcome), multiply along the branches you followed.
  5. All the path probabilities in the whole tree must sum to 1 — that's your accuracy check.

Law of Total Probability

This is how you find the probability of an event B when B can happen via several different "routes" (partitions) \(A_1, A_2, \ldots, A_k\) that are mutually exclusive and collectively exhaustive (they cover every possibility with no overlap):

\[P(B) = \sum_{i=1}^{k} P(A_i)\,P(B\mid A_i)\]

In plain language: to get the overall chance of B, go down every possible route to B, multiply each route's own probability by the chance of B happening along that route, and add all the routes together.

🎓 Professor's Thought

This is precisely the DENOMINATOR you will compute in every single Bayes' Theorem problem. If you can compute Law of Total Probability comfortably, Bayes' Theorem is just one more division step on top of something you already know how to do. Don't study them as two separate topics — they are one skill in two acts.

Bayes' Theorem — "Reversing" a Conditional Probability

Bayes' Theorem lets you flip the condition around: if you know \(P(B\mid A)\) but the question actually wants \(P(A\mid B)\), this is the tool.

For two mutually exclusive, collectively exhaustive events \(A_1, A_2\): \[P(A_1 \mid B) = \frac{P(B\mid A_1)\,P(A_1)}{P(B\mid A_1)P(A_1) + P(B\mid A_2)P(A_2)}\] General form for n events: \[P(A_m \mid B) = \frac{P(B\mid A_m)\,P(A_m)}{\sum_{i=1}^{n} P(B\mid A_i)\,P(A_i)}\]

Vocabulary you must know cold, because exam wording relies on it:

Prior probability — \(P(A_i)\), what you believed BEFORE the new evidence B arrived.
Likelihood — \(P(B\mid A_i)\), how likely the evidence is under each scenario.
Posterior probability — \(P(A_i\mid B)\), your UPDATED belief AFTER seeing the evidence — this is what Bayes' Theorem computes.
Worked Example

A firm believes it has a 50-50 chance of winning a bid. Past data: 75% of successful bids and 40% of unsuccessful bids get a request for more information. The agency asks for more info. Find the posterior probability that the bid is successful.

Solution: Let \(A_1\)=successful, \(A_2\)=unsuccessful, B=info requested.
\(P(A_1)=P(A_2)=0.5\), \(P(B\mid A_1)=0.75\), \(P(B\mid A_2)=0.40\).

\[P(A_1\mid B)=\frac{0.75\times0.5}{(0.75\times0.5)+(0.40\times0.5)}=\frac{0.375}{0.575}=0.652\]
Answer: 0.652 (posterior probability the bid was successful)
Exercise — Solved

12% of men develop prostate cancer. A man WITH cancer tests positive 95% of the time; a man WITHOUT cancer gets a false positive 6% of the time. Find P(has cancer | tested positive).

Solution: Let C = has cancer, T+ = positive test.
\(P(C)=0.12\), \(P(C')=0.88\), \(P(T^+\mid C)=0.95\), \(P(T^+\mid C')=0.06\).

\[P(C\mid T^+)=\frac{0.95\times0.12}{(0.95\times0.12)+(0.06\times0.88)}=\frac{0.114}{0.1668}\approx0.6835\]
Answer: ≈ 0.6835
🎓 Professor's Thought

This is the textbook "base rate" trap that shows up in nearly every Bayes' set on the exam: even with a 95%-accurate test, if the disease itself is rare (only 12% here), the posterior probability isn't anywhere near 95% — it lands around 68%. Students who don't compute the full denominator (i.e. skip adding the false-positive branch from the healthy population) will wrongly answer 0.95. ALWAYS compute both branches of the Law of Total Probability denominator, even when one branch's prior looks small — it usually isn't negligible.

Exercise — Solved

Insurance risk classes: good (20%, accident rate 0.05), average (50%, accident rate 0.15), bad (30%, accident rate 0.30). (a) Overall accident rate? (b) If NO accident occurred, P(good risk)?

(a) Solution: \(P(B)=(0.05)(0.2)+(0.15)(0.5)+(0.30)(0.3)=0.01+0.075+0.09=0.175\)

Answer (a): 0.175

(b) Solution: Need \(P(B')=1-0.175=0.825\) and \(P(B'\mid A_1)=1-0.05=0.95\).

\[P(A_1\mid B') = \frac{0.95\times0.20}{0.825} = 0.2303\]
Answer (b): ≈ 0.230 (23%)
Exercise — Solved

A diagnostic test: P(positive | sufferer) = 0.95, P(positive | non-sufferer) = 0.10, P(sufferer) = 0.005. Find (a) P(positive), (b) P(sufferer | positive), (c) P(non-sufferer | negative), (d) P(misclassified).

(a) \(P(+) = (0.95)(0.005) + (0.10)(0.995) = 0.00475 + 0.0995 = 0.10425\)

Answer (a): 0.10425

(b) \(P(\text{sufferer}\mid +) = \frac{0.00475}{0.10425} \approx 0.0456\)

Answer (b): ≈ 0.0456

(c) \(P(-) = 1-0.10425 = 0.89575\). \(P(\text{non-suff}\cap -) = 0.995\times0.90=0.8955\). \(P(\text{non-suff}\mid -) = \frac{0.8955}{0.89575}\approx0.99972\)

Answer (c): ≈ 0.9997

(d) Misclassified = (sufferer AND tested negative) OR (non-sufferer AND tested positive):
\(=(0.005\times0.05)+(0.995\times0.10)=0.00025+0.0995=0.09975\)

Answer (d): ≈ 0.0998 (9.98%)

Lecture 12 — Random Variables (PMF, PDF, CDF)

What Is a Random Variable?

A random variable is a rule that assigns a NUMBER to every outcome of a random experiment. It's the bridge between "an outcome happened" and "here's a number I can do math with." Example: flip two fair coins, \(S=\{HH,HT,TH,TT\}\). Let X = number of heads. Then X turns each outcome into a number: HH→2, HT→1, TH→1, TT→0. Now X can only be 0, 1, or 2, each with its own probability.

🎓 Professor's Thought

Students often ask "why bother defining X at all — why not just work with the outcomes directly?" Because outcomes like HH or TH aren't numbers, you can't average them, plot them, or feed them into a formula. Once you convert to X, you unlock the entire toolkit of expectation, variance, and every named distribution in this course. Defining a sensible random variable is often the FIRST and most important step in solving a word problem — get X's definition wrong, and everything downstream breaks.

Discrete vs. Continuous

Discrete random variable — takes a finite or countably infinite list of separate values (you could in principle list them: 0,1,2,3,...). Examples: number of calls received per day, number of defective items in a batch.
Continuous random variable — can take ANY value in an interval (uncountably many possibilities — you could never finish listing them). Examples: time to serve a customer, temperature, height.

Probability Mass Function (PMF) — for Discrete X

The PMF \(f(x)\) gives the exact probability that X equals a specific value:

\[f(x) = P(X=x_i), \quad i=1,2,\ldots,n\]

A valid PMF must satisfy two rules — these are your go-to "verify it's a valid PMF" checks:

Rule 1: \(0 \le f(x_i) \le 1\) for every value

Rule 2: \(\sum_i f(x_i) = 1\) (all probabilities add to exactly 1)
Worked Example

X has pmf: f(2)=2/10, f(4)=1/10, f(6)=4/10, f(8)=3/10. Find P(X=4), P(X>4), P(X≤6), P(2<X≤8).

Solution: \(P(X=4)=\frac{1}{10}\).
\(P(X>4)=P(6)+P(8)=\frac{4}{10}+\frac{3}{10}=\frac{7}{10}\)
\(P(X\le6)=P(2)+P(4)+P(6)=\frac{2}{10}+\frac{1}{10}+\frac{4}{10}=\frac{7}{10}\)
\(P(2<X\le8)=P(4)+P(6)+P(8)=\frac{8}{10}\)

🎓 Professor's Thought

Watch the boundary symbols like a hawk: ">" excludes the value, "≥" includes it. In the example, P(2<X≤8) INCLUDES X=8 but EXCLUDES X=2 — that single difference changes which pmf values you sum. Underline every inequality symbol in the question before you start summing; this is the #1 avoidable error in PMF questions.

Probability Density Function (PDF) — for Continuous X

For continuous X, you cannot ask "what's P(X = exact single value)?" — that's always 0, because there are infinitely many possible values crammed into any interval, so any one exact point has zero "share." Instead, probability is the AREA under a curve f(x) over a range:

\[P(a \le X \le b) = \int_a^b f(x)\,dx\]

A valid PDF must satisfy:

Rule 1: \(f(x) \ge 0\) everywhere

Rule 2: \(\int_{-\infty}^{\infty} f(x)\,dx = 1\) (total area under the whole curve = 1)
Crucial fact: for continuous X, \(P(X=k)=0\) for any single point k. This means \(P(X\le k)\), \(P(X<k)\), \(P(X\ge k)\), and \(P(X>k)\) are all EQUAL for continuous variables — unlike discrete variables where boundary inclusion matters.
Worked Example

f(x) = x for 0≤x<1, f(x)=2−x for 1≤x<2, f(x)=0 elsewhere. (a) Verify it's a valid pdf. (b) Find P(0.5≤X≤1.5).

(a) \(\int_0^1 x\,dx + \int_1^2 (2-x)\,dx = \left[\frac{x^2}{2}\right]_0^1 + \left[2x-\frac{x^2}{2}\right]_1^2 = 0.5+0.5=1\) ✓ valid.

(b) \(\int_{0.5}^{1}x\,dx + \int_1^{1.5}(2-x)\,dx = \left[\frac{x^2}{2}\right]_{0.5}^{1} + \left[2x-\frac{x^2}{2}\right]_1^{1.5} = 0.375+0.375=0.75\)

Answer: 0.75

Cumulative Distribution Function (CDF)

The CDF \(F(x)\) is the running total: "probability that X is at most x." It works the same way for both discrete and continuous variables, though it's computed differently for each:

\[F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\,dt \quad \text{(continuous)}\]

Two facts you must memorize about how PDF and CDF relate:

To go PDF → CDF: integrate.
To go CDF → PDF: differentiate. \[f(x) = \frac{d}{dx}F(x)\]
Worked Example

Given f(x)=2x for 0<x<1, find the CDF F(x).

Solution: \(F(x)=\int_0^x 2t\,dt = x^2\) for 0<x<1, and F(x)=1 for x≥1, F(x)=0 for x<0.

Exercise — Solved

Given F(x) = x² for 0<x<1, F(x)=1 for x≥1. Find the PDF f(x).

Solution: Differentiate: \(f(x)=\frac{d}{dx}(x^2)=2x\) for 0<x<1, and f(x)=0 otherwise.

Answer: f(x) = 2x, 0 < x < 1; 0 otherwise
🎓 Professor's Thought

This CDF↔PDF pair (F(x)=x² and f(x)=2x) is a favorite exam recycling target because it's simple enough to test both directions of the same skill in one sitting. If you can do this conversion instantly in both directions, you've essentially covered the "Random Variables" portion of any exam set involving PDF/CDF derivation.

Lecture 13–14 — Expectation, Variance & Joint Distributions

Mathematical Expectation E[X] — the "Long-Run Average"

The expectation of a random variable is the weighted average of its possible values, where each value is weighted by how likely it is. Think of it as: "if I repeated this experiment forever and averaged the results, what number would I converge to?"

Discrete: \[\mu = E[X] = \sum_i x_i f(x_i)\] Continuous: \[\mu = E[X] = \int_{-\infty}^{\infty} x f(x)\,dx\] General function g(X): \[E[g(X)] = \sum g(x)f(x) \text{ (discrete)} \quad\text{or}\quad \int g(x)f(x)\,dx \text{ (continuous)}\]
Worked Example

A game: 20% chance of winning Tk. 30, 80% chance of losing Tk. 10. Find the expected gain.

Solution: \(E(X) = (30\times0.2)+(-10\times0.8) = 6-8 = -2\)

Answer: −2 Tk (expect to lose 2 Tk per play, on average)

Properties of Expectation (Linearity)

These let you shortcut calculations without redoing the whole sum every time X gets shifted or scaled:

\(E[c] = c\)  (a constant's "average" is itself)
\(E[cX] = cE[X]\)
\(E[X+c] = E[X]+c\)
\(E[X+Y] = E[X]+E[Y]\) (always true, dependent or not)
\(E[X-Y] = E[X]-E[Y]\)
If X, Y independent: \(E[XY]=E[X]E[Y]\)

Variance and Standard Deviation

Variance measures spread — how far values typically wander from the mean. Bigger variance = more unpredictable.

\[Var(X) = E(X^2) - [E(X)]^2\] \[SD(X) = \sqrt{Var(X)}\]

Properties of variance — note these are NOT the same shape as expectation's properties, which is exactly why exams test them together:

\(V[c]=0\) (a constant never varies)
\(V[cX] = c^2 V[X]\)  (the constant gets SQUARED — common slip: forgetting the square)
\(V[X+c] = V[X]\)  (shifting everything by a constant doesn't change the spread)
\(V[X+Y]=V[X]+V[Y]\) if X, Y independent
\(V[X-Y]=V[X]+V[Y]\) if X, Y independent (NOT minus — see Professor's Thought)
🎓 Professor's Thought

Two traps live in this box. First: \(V[cX]=c^2V[X]\), not \(cV[X]\) — squaring the constant is mandatory because variance itself is defined using squared deviations. Second, and more commonly missed: even for \(V[X-Y]\), you ADD the variances, you never subtract — variability from two independent sources always accumulates, it never cancels out, even when you're subtracting the variables themselves. If a slide or classwork sheet shows "V[X−Y]=V[X]−V[Y]," that's almost certainly a typo — always add.

Coefficient of Variation (CV)

\[CV(X) = \frac{SD(X)}{E(X)}\]

CV is a UNITLESS measure of relative spread — useful for comparing riskiness/variability across datasets with different units or different scales of mean.

Worked Example

A new café: 20% chance of Tk.50,000 loss, 30% no profit/loss, 40% chance of Tk.50,000 profit, 10% chance of Tk.150,000 profit. Find E(X), SD(X), CV(X).

Solution: \(E(X)=(-50000)(0.2)+0(0.3)+(50000)(0.4)+(150000)(0.1)=25000\)
\(E(X^2)=(50000^2)(0.2)+0+(50000^2)(0.4)+(150000^2)(0.1)=3.75\times10^{10}\)
\(V(X)=3.75\times10^{10}-25000^2=3.125\times10^{10}\) → \(SD(X)=55901.69\)
\(CV=\frac{55901.69}{25000}\times100\%=223.6\%\)

E(X)=25,000 · SD(X)≈55,901.69 · CV≈223.6%

Joint, Marginal, and Conditional Distributions

So far we've only looked at ONE random variable at a time. Now we look at TWO random variables observed together — like a server's failures (X) and a second server's failures (Y) in the same monitoring window.

Joint PMF (Discrete)

\(P_{X,Y}(x,y) \ge 0\) for all x,y
\(\sum_x\sum_y P_{X,Y}(x,y) = 1\)

Marginal Distributions — "Collapse One Variable Away"

The marginal of X is just: ignore Y entirely, sum across every Y value for each fixed x. It answers "what's the distribution of X alone, forgetting Y ever existed?"

\[P_X(x) = \sum_y P_{X,Y}(x,y) \qquad P_Y(y) = \sum_x P_{X,Y}(x,y)\]
🎓 Professor's Thought

Mechanically: if your joint table has X across the top and Y down the side, the marginal of X is the COLUMN SUMS (written along the bottom row), and the marginal of Y is the ROW SUMS (written along the right column). Students often flip this by accident — always double check that your marginal-of-X values actually vary WITH x, not with y.

Conditional Distributions

\[P_{X\mid Y}(x\mid y) = \frac{P_{X,Y}(x,y)}{P_Y(y)} \qquad P_{Y\mid X}(y\mid x) = \frac{P_{X,Y}(x,y)}{P_X(x)}\]

Testing Independence

X and Y are independent if and only if the joint pmf equals the product of the marginals for EVERY combination of x and y:

\[P_{X,Y}(x,y) = P_X(x)\,P_Y(y) \quad \text{for all } x,y\]
🎓 Professor's Thought

You only need ONE failing combination to prove NOT independent — you don't need to check every cell. But to prove independence holds, you DO need to verify every single cell, because one mismatch anywhere breaks it. In practice, on an exam, if you're asked to "determine independence," look for the cell most likely to break the pattern first (often a zero-probability cell) — check that one first to save time.

Worked Example

Joint pmf table for X,Y (values 0,1,2 each). Given the joint table, marginals P(X)=P(Y)=(0.3,0.3,0.4). (a) Determine independence at X=0,Y=0 where joint P=0.1. (b) Find P(Y=2|X=1) if that joint cell = 0.

(a) \(P(0)\times P(0) = 0.3\times0.3=0.09 \ne 0.1\) → NOT independent.

Answer (a): Not independent (0.1 ≠ 0.09)

(b) \(P(Y=2\mid X=1)=\frac{0}{0.3}=0\)

Answer (b): 0

Continuous Joint Distributions

Everything above has a continuous analogue — swap sums for integrals:

Joint pdf validity: \(f_{X,Y}(x,y)\ge0\) and \(\int_x\int_y f_{X,Y}(x,y)\,dy\,dx=1\)

Marginal pdf: \[f_X(x)=\int_y f_{X,Y}(x,y)\,dy \qquad f_Y(y)=\int_x f_{X,Y}(x,y)\,dx\] Conditional pdf: \[f_{X\mid Y}(x\mid y)=\frac{f_{X,Y}(x,y)}{f_Y(y)}\]
🎓 Professor's Thought

The continuous joint-distribution questions in your classwork (Q1–Q6, 23rd August sheet) are the most calculation-heavy of the whole midterm-to-final syllabus bridge — they combine double integration, marginal derivation, AND conditional probability in one problem. Budget extra time for these specifically; they are unlikely to appear as a full 7-mark set on the final (Joint Probability is its own declared set), but partial versions can sneak into a Random Variables-flavored question.

Lecture 15–16 — Special Discrete Distributions

⭐ High-yield: this cluster feeds directly into 3 of your 5 declared exam question sets (Discrete Special Distribution).

The Bernoulli Trial — the Building Block

Before Binomial, you need a Bernoulli trial: a single experiment with exactly two outcomes (success/failure), where:

  1. Only two possible outcomes per trial.
  2. Probability of success p stays CONSTANT across trials (so failure probability q = 1−p is also constant).
  3. A fixed number of trials, n.
  4. Trials are independent of each other.
🎓 Professor's Thought

Before writing any binomial/geometric/Poisson formula on the exam, explicitly check these four conditions against the word problem in one line — "n=20 trials, p=0.04 constant, independent selections" — because examiners sometimes embed a violation (e.g., sampling without replacement from a small population, which breaks independence and would need hypergeometric instead) to test if you're checking assumptions rather than pattern-matching keywords.

Binomial Distribution — "How many successes in n fixed trials?"

\[f(x) = \binom{n}{x}p^xq^{n-x}, \quad x=0,1,\ldots,n\]
Mean: \(E(X) = np\)
Variance: \(V(X) = npq\)

Use Binomial when: fixed number of trials n, each trial succeeds with the same p, and you're counting the TOTAL number of successes.

Worked Example

4% of BRACU graduates are unemployed. From a sample of 20, find (a) P(exactly 5 unemployed), (b) P(none unemployed), (c) P(≤2 unemployed), (d) P(≥3 unemployed).

Solution: n=20, p=0.04.
(a) \(P(X=5)=\binom{20}{5}(0.04)^5(0.96)^{15}\approx0.00009\)
(b) \(P(X=0)=(0.96)^{20}\approx0.442\)
(c) \(P(X\le2)=\sum_{x=0}^{2}\binom{20}{x}(0.04)^x(0.96)^{20-x}\approx0.956\)
(d) \(P(X\ge3)=1-0.956=0.044\)

(a) 0.00009 (b) 0.442 (c) 0.956 (d) 0.044
🎓 Professor's Thought

"At least," "at most," "no more than," "fewer than," "between...inclusive" are the phrases that decide whether you sum P(X=0) through P(X=k) or use the complement 1 − P(X≤k−1). Build yourself a quick translation table before the exam: "at least k" = P(X≥k) = 1−P(X≤k−1); "more than k" = P(X≥k+1); "at most k" = P(X≤k); "fewer than k" = P(X≤k−1). Getting the boundary off by one is the single most common way marks are lost on binomial/Poisson problems.

Geometric Distribution — "How many trials until the FIRST success?"

\[f(x) = pq^{x}, \quad x=0,1,2,\ldots \quad (\text{"x = number of failures before first success" convention})\]

Careful — two conventions exist depending on whether X counts trials-including-the-success or failures-before-success. Your practice-problem PDF uses the "number of trials until first success" convention:

\[P(X=x) = p(1-p)^{x-1}, \quad x=1,2,3,\ldots\]
Mean: \(E(X) = \frac{1}{p}\)
Variance: \(V(X) = \frac{1-p}{p^2}\)  (some textbooks/slides write \(\frac{q}{p^2}\) — same thing since q=1−p)
🎓 Professor's Thought — Confirmed Against Your Actual Exam Formula Sheet

Your uploaded faculty formula sheet settles this definitively: it lists \(f(x)=pq^x\) for \(x=0,1,2,\ldots\) — the "failures before success" convention — as the OFFICIAL exam-hall formula. Treat that as your default. Still, always read what a specific problem's own wording defines X to be: if a problem explicitly says "X = the number of trials required" or "the trial on which success first occurs," it has locally redefined X to the trials-until-success convention, and you should use \(pq^{x-1}\) for that problem instead — but if nothing is specified, default to your faculty's own \(pq^x\), x=0,1,2,.... Converting between them is simple: trial-number X = failures-count X + 1, so E(X)=q/p (failures-count) becomes E(X)=q/p+1=1/p (trial-number) — the two mean formulas you see across different sources are not contradicting each other, they're just counting a slightly different thing.

Worked Example

Optical alignment success rate p=0.8. Find (a) P(exactly 4th trial is first success), (b) P(at most 4 trials), (c) P(at least 4 trials).

Solution: Using \(P(X=x)=0.8(0.2)^{x-1}\)
(a) \(P(X=4)=0.8(0.2)^3=0.0064\)
(b) \(P(X\le4)=0.8+0.16+0.032+0.0064=0.9984\)
(c) \(P(X\ge4)=1-P(X\le3)=1-0.992=0.008\)

(a) 0.0064 (b) 0.9984 (c) 0.008

Poisson Distribution — "How many rare events in a fixed interval?"

\[f(x) = \frac{e^{-\lambda}\lambda^x}{x!}, \quad x=0,1,2,\ldots, \ \lambda>0\]
Mean: \(E(X)=\lambda\)    Variance: \(V(X)=\lambda\)
Unique fact worth memorizing: Poisson is the ONLY named distribution in this course where mean = variance, both equal to λ. If a question's answer gives you unequal "mean" and "variance" for something you assumed was Poisson, you've made an arithmetic error — go back and check.

Rescaling λ for a Different Time/Space Window

This is the step students most often forget: λ is defined PER a specific interval. If the question asks about a DIFFERENT length interval, you must rescale λ proportionally first.

Worked Example

A bookstore sells 27 novels in 9 hours (Poisson). Find P(exactly 5 novels sold in ONE hour).

Solution: Rescale: \(\lambda_{\text{per hour}} = \frac{27}{9}=3\). Then \(P(X=5)=\frac{e^{-3}3^5}{5!}\approx0.1008\)

Answer: ≈ 0.1008
🎓 Professor's Thought

Whenever a Poisson question mentions TWO different time spans (e.g. "average per day" but asks "probability in a week," or "average per 10,000 population" but asks about a city of 200,000"), the very first line of your solution should be the λ-rescaling step, written explicitly: "λ_new = λ_given × (new interval / given interval)." Examiners plant this rescaling requirement specifically to separate students who understand the parameter from those who've only memorized the formula.

Exercise — Solved

Average of 3.0 accidental drownings per 10,000 population per year. In a city of 200,000, find P(exactly 2 drownings), P(at least 3), P(between 4 and 8 inclusive).

Solution: Rescale: \(\lambda = 200000\times\frac{3}{10000}=60/10=6\). So \(X\sim Poisson(6)\).
(a) \(P(X=2)=\frac{e^{-6}6^2}{2!}\approx0.0446\)
(b) \(P(X\ge3)=1-P(X\le2)\approx1-0.062=0.938\)
(c) \(P(4\le X\le8)\approx0.6964\) (sum of individual Poisson terms x=4 to 8)

(a) 0.0446 (b) 0.938 (c) 0.6964

Expanded Concept — Binomial vs. Hypergeometric (an important discrepancy to catch)

The Binomial distribution REQUIRES independent trials with constant p — this is only exactly true when sampling WITH replacement, or when sampling from an effectively infinite population. Several problems in your classwork/practice sets (the jar-of-sweets problem, the battery-selection problem, the hard-drive-sectors-style "choose 2 from a small group" problems) sample WITHOUT replacement from a SMALL population — technically, this is the Hypergeometric distribution, not Binomial, because removing an item changes the probability for the next draw (trials are no longer independent).

Hypergeometric pmf (for reference — not deeply covered in your slides, but the mechanism behind several "without replacement" problems): \(P(X=x)=\dfrac{\binom{K}{x}\binom{N-K}{n-x}}{\binom{N}{n}}\), where N=population size, K=number of "successes" in the population, n=sample size drawn.
🎓 Professor's Thought

In practice, when your classwork/practice sets solved these "without replacement" problems, they used the direct combinatorial counting approach (favorable outcomes ÷ total outcomes via combinations) rather than explicitly naming "Hypergeometric" — and that approach gives the mathematically correct answer regardless of what you call the distribution. The key exam takeaway: if a problem says "without replacement" or "no replacement" from a SMALL, explicitly-sized population, do NOT plug it into the Binomial formula \(\binom nx p^xq^{n-x}\) with a fixed p — instead count directly with combinations, exactly as done in the Random Variables battery-selection problem (Tab 2 / Tab 4). If the population is large enough that removing a few items barely changes the proportion (e.g. "4% of BRACU graduates," a population of thousands), Binomial remains a perfectly good approximation even without replacement — this is why the graduate-unemployment and hypertension-sample problems correctly use Binomial despite technically sampling without replacement from a finite population.

⭐ High-yield: Normal Distribution problems are near-guaranteed on the final (2 of your 3 Discrete/Continuous sets typically draw from here + Test of Hypothesis needs Z-values too).

Exponential Distribution — "Time until the next event"

Where Poisson counts EVENTS in a fixed interval, Exponential measures the WAITING TIME until the next event (or between events) in a Poisson process.

\[f(x) = \lambda e^{-\lambda x}, \quad x>0, \lambda>0\]
\[F(x) = 1-e^{-\lambda x} \qquad E(X)=\frac{1}{\lambda} \qquad V(X)=\frac{1}{\lambda^2}\]
🎓 Professor's Thought

Notice E(X) and V(X) share the same λ but E(X) and SD(X) are BOTH equal to 1/λ (since SD = √(1/λ²) = 1/λ). This is a distinctive Exponential fingerprint — if a slide/exercise asks you to "prove mean and SD are equal for exponential," this is exactly why: it falls straight out of the variance formula, no extra derivation trick needed.

Worked Example

Phone call length ~ Exponential(λ=0.1). Find P(wait > 10 min) and P(10<X<20).

Solution: \(P(X>10)=1-F(10)=e^{-1}=0.368\)
\(P(10<X<20)=F(20)-F(10)=e^{-1}-e^{-2}=0.368-0.135=0.233\)

P(X>10)=0.368, P(10<X<20)=0.233

Normal Distribution — the Bell Curve

\[f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}, \quad -\infty<x<\infty\]

Two parameters fully describe it: \(\mu\) (mean — the center) and \(\sigma^2\) (variance — the spread). It is symmetric about μ, bell-shaped, and never touches zero at the tails.

\[E(X)=\mu \qquad V(X)=\sigma^2\]

The Standard Normal Distribution & Z-Scores

Since every Normal distribution has a different μ and σ, we can't have one universal table for all of them — so we STANDARDIZE. Any Normal variable X can be converted into Z, which always has mean 0 and variance 1:

\[Z = \frac{X-\mu}{\sigma} \sim N(0,1)\]

This single formula is the most-used tool in the entire final exam — it's what lets you look up ANY Normal probability using ONE Z-table.

🎓 Professor's Thought

Think of Z as answering: "how many standard deviations away from the mean is this value?" A Z of +2 means "2 SDs above average" — that's it, that's the whole intuition. Once you have Z, the Z-table gives you the AREA TO THE LEFT of that Z value, which IS the cumulative probability P(Z ≤ z) = Φ(z). Everything else (right-tail, between two values, etc.) is just arithmetic on top of that one lookup.

Reading the Z-Table (exact table you'll get on exam day)

The table entry for a given z is the area under the curve to the LEFT of z — i.e. \(P(Z\le z) = \Phi(z)\). To read a value like z = 1.67: find row "1.6," column ".07," read off 0.9525.

The Four Patterns You'll Ever Need

\(P(Z<z) = \Phi(z)\) — direct table lookup

\(P(Z>z) = 1-\Phi(z)\) — right tail = 1 minus table value

\(P(z_1<Z<z_2) = \Phi(z_2)-\Phi(z_1)\) — between = subtract the two table values

🎓 Professor's Thought

Your Z-table (uploaded) already lists BOTH negative and positive z rows directly — so you do NOT need the "1 − Φ(z)" symmetry trick for negative z; just read the negative-z row straight from the table. Save the symmetry trick specifically for RIGHT-TAIL (greater-than) questions on POSITIVE z, where the table doesn't give you the right-hand area directly.

Worked Example

Heights ~ N(68, 3²). Find (a) P(X>72), (b) P(X≥65), (c) P(X≤64), (d) P(60<X<65).

(a) \(Z=\frac{72-68}{3}=1.33\), \(P(X>72)=1-\Phi(1.33)=1-0.9082=0.0918\)

(b) \(Z=\frac{65-68}{3}=-1.00\), \(P(X\ge65)=1-\Phi(-1.00)=1-0.1587=0.8413\)

(c) \(Z=\frac{64-68}{3}=-1.33\), \(P(X\le64)=\Phi(-1.33)=0.0918\)

(d) \(Z_1=\frac{60-68}{3}=-2.67,\ Z_2=\frac{65-68}{3}=-1.00\), \(P=\Phi(-1.00)-\Phi(-2.67)=0.1587-0.0038=0.1549\)

(a) 0.0918 (b) 0.8413 (c) 0.0918 (d) 0.1549

Working Backwards: Given a Probability, Find X (Percentile Problems)

Sometimes the question flips: instead of "find P(X<k)," it gives you the probability and asks for k. Reverse the process — look up the Z that matches the given probability INSIDE the table body, then un-standardize:

\[X = \mu + Z\sigma\]
Worked Example

Transactions ~ N(70,3²). Find the amount corresponding to the top 10% of transactions.

Solution: Top 10% means 90th percentile, so find z where \(\Phi(z)=0.90\) → z≈1.28.
\(X=70+(1.28)(3)=73.84\)

Answer: ≈ $73.84
🎓 Professor's Thought

"Solve for σ" and "solve for μ" problems (both appear in your practice set) are just this same backwards process, done algebraically instead of arithmetically: you still find z from the given probability first, then rearrange \(z=\frac{x-\mu}{\sigma}\) for whichever unknown you need. These look intimidating because they hand you a Z indirectly through a probability, but the mechanics never change — find z, then solve one linear equation.

Sampling Distribution of the Mean (a preview for Hypothesis Testing)

When you take a SAMPLE of size n and look at the sample MEAN's distribution (rather than one individual X), the standard deviation shrinks by a factor of √n:

\[Z = \frac{\bar{x}-\mu}{\sigma/\sqrt{n}}\]

This exact formula is the test statistic you will use throughout Lecture 19–20 (Hypothesis Testing) — so mastering it here pays double.

Lecture 19–20 — Test of Hypothesis

⭐ Mandatory exam set — 1 full 7-mark question guaranteed on this topic.

Why Hypothesis Testing Exists

Descriptive statistics summarizes data you HAVE. Inferential statistics uses a SAMPLE to draw conclusions about a whole POPULATION you can't fully observe. A hypothesis test is a formal procedure to decide whether a claim about a population parameter (like the mean) is believable given your sample data, or whether the sample data contradicts it strongly enough to reject the claim.

Two Competing Statements

Null Hypothesis, H₀ — the "status quo" statement: no effect, no difference, business-as-usual. This is what you assume TRUE unless the data gives strong evidence against it.
Alternative Hypothesis, H₁ (or Hₐ) — the claim you're actually trying to find support for; "there IS an effect/difference."
🎓 Professor's Thought

H₀ ALWAYS contains the equals sign (=, ≥, or ≤ — but always includes equality). H₁ never does (<, >, or ≠ only). If you're ever unsure which hypothesis is which while translating a word problem, just ask: "which statement includes the word 'equal' or 'no different from'?" — that's always H₀.

One-Tailed vs Two-Tailed — Reading the Words

Wording in the problemHypothesis formTest type
"is smaller than / less than / decreased"H₁: μ < μ₀Left-tailed
"is greater than / higher / increased"H₁: μ > μ₀Right-tailed
"is different from / not equal to / changed"H₁: μ ≠ μ₀Two-tailed

The Seven Key Steps

  1. Set up H₀ and H₁
  2. Choose the significance level α (usually given: 1%, 5%, or 10%)
  3. Choose the appropriate test statistic
  4. Set up the decision rule (find the critical value(s))
  5. Calculate the test statistic from the sample
  6. Make a decision — reject or fail to reject H₀
  7. Interpret the decision in the context of the actual question
🎓 Professor's Thought

On a 90-minute, 5-question exam, you do NOT have time to write a full essay for step 7 — one clear sentence restating the conclusion IN CONTEXT ("the data supports the claim that mean delivery time is less than 120 minutes") is exactly what earns that mark, no more needed. Examiners specifically want to see you interpret back into the original units and context, not just say "we reject H₀."

The Test Statistic (Z-test, known σ)

\[Z_{cal} = \frac{\bar{x}-\mu_0}{\sigma/\sqrt{n}} \sim N(0,1)\]

This is exactly the standardization formula from L17–18, applied to a SAMPLE MEAN instead of a single observation.

Decision Rule — Critical Value Approach (by tail type)

Right-tailed (H₁: μ > μ₀): critical value = \(Z_{1-\alpha}\). Reject H₀ if \(Z_{cal} > Z_{1-\alpha}\)

Left-tailed (H₁: μ < μ₀): critical value = \(Z_{\alpha}\). Reject H₀ if \(Z_{cal} < Z_{\alpha}\)

Two-tailed (H₁: μ ≠ μ₀): critical values = \(\pm Z_{1-\alpha/2}\). Reject H₀ if \(Z_{cal} > Z_{1-\alpha/2}\) or \(Z_{cal} < -Z_{1-\alpha/2}\)
🎓 Professor's Thought

Common critical values worth memorizing outright so you don't burn exam time deriving them: for α=0.05, one-tailed critical Z = 1.645 (often written 1.64); two-tailed critical Z = ±1.96. For α=0.01: one-tailed ≈ 2.33; two-tailed ≈ ±2.575 (often 2.58). These four numbers cover the overwhelming majority of hypothesis-testing questions you'll see.

Decision Rule — p-value Approach (equivalent, alternate method)

If p-value ≤ α → reject H₀
If p-value > α → fail to reject H₀

The smaller the p-value, the stronger the evidence AGAINST H₀. p-value is computed as the tail-area probability beyond your calculated Z, matching the direction of your test (right tail for right-tailed test, both tails doubled for two-tailed).

Type I and Type II Errors

Decision \ TruthH₀ is TrueH₀ is False
Fail to reject H₀Correct decisionType II Error (β)
Reject H₀Type I Error (α)Correct decision (Power = 1−β)
Type I Error — rejecting a TRUE null hypothesis (a "false alarm"). Probability = α, which you choose yourself before the test.
Type II Error — failing to reject a FALSE null hypothesis (a "missed detection"). Probability = β.
Power — probability of correctly rejecting a false H₀ = 1−β. Higher power = better test.
Worked Example — Full 7-step Walkthrough

A sample of 49 orders has mean delivery time 100 min, population σ=30 min. Shop claims mean delivery time is LESS than 120 min. Test at α=0.05.

Step 1: H₀: μ=120, H₁: μ<120 (left-tailed)
Step 2: α=0.05
Step 3: Z-test (σ known): \(Z=\frac{\bar x-\mu_0}{\sigma/\sqrt n}\)
Step 4: Reject H₀ if \(Z_{cal} < Z_{0.05}=-1.64\)
Step 5: \(Z_{cal}=\frac{100-120}{30/\sqrt{49}}=\frac{-20}{4.286}=-4.99\)
Step 6: Since −4.99 < −1.64, reject H₀.
Step 7: The data provides sufficient evidence, at the 5% significance level, that the true mean delivery time is less than 120 minutes.

Decision: Reject H₀ — mean delivery time IS less than 120 min
Exercise — Solved

n=25 adults, sample mean IQ=105, σ=15. Test H₀: μ=100 vs H₁: μ≠100 at α=0.05.

Solution: Two-tailed, critical Z = ±1.96.
\(Z_{cal}=\frac{105-100}{15/\sqrt{25}}=\frac{5}{3}=1.67\)
Since 1.67 < 1.96, we FAIL to reject H₀.

Decision: Fail to reject H₀ — insufficient evidence mean IQ ≠ 100
🎓 Professor's Thought

Notice the phrasing discipline in both conclusions: we NEVER say "we accept H₀" or "H₀ is true" — we only ever say "fail to reject H₀." This is because absence of strong evidence against H₀ isn't the same as proof H₀ is correct. Examiners specifically watch for this phrasing, and marks are commonly deducted for writing "we accept the null hypothesis."

When σ Is NOT Known: the T-test

Everything above assumed the population standard deviation σ was given to you directly. Sometimes it isn't — you only have your sample data, and you must ESTIMATE the spread from that sample itself. When that happens, you can no longer use Z; you switch to the t-statistic, and the reference distribution changes from Normal to the t-distribution.

Sample standard deviation (estimated from your own data): \[s=\sqrt{\frac{\sum x_i^2-n\bar x^2}{n-1}}\] Test statistic: \[T=\frac{\bar x-\mu_0}{s/\sqrt n}\sim t_{n-1}\]
Degrees of freedom (n−1) — once you\'ve used your n data points to calculate their own mean x̄, only n−1 of them are still "free" to vary independently; the last value is forced by the constraint that they must all average to x̄. This is why the t-distribution\'s exact shape depends on n−1, not n, and why its critical values come from a SEPARATE t-table indexed by degrees of freedom, not the Z-table.
🎓 Professor\'s Thought

The decision rule is otherwise IDENTICAL to the Z-test — same H₀/H₁ setup, same "reject if the calculated statistic exceeds the critical value" logic, same p-value interpretation — you\'re just swapping which statistic and which table you use. The one thing to check first, every time: does the problem give you the population σ directly, or only sample data you\'d have to compute s from? That single check tells you whether to reach for Z or T. Since your exam provides a Z-table specifically, expect population σ to be given directly in virtually every hypothesis-testing question you\'ll actually face — but knowing the T-test exists, and being able to state the formula and explain degrees of freedom, protects you if a conceptual (non-numeric) question about it appears.

Slide Example — Contingency Table

Smoking/cancer contingency table: Smoker∩Cancer=7860, Smoker∩NoCancer=1530 (Smoker total=9390); NonSmoker∩Cancer=5390, NonSmoker∩NoCancer=11580 (NonSmoker total=16970); Grand total=26360. Find (a) P(smoker), (b) P(cancer), (c) P(smoker∩cancer), (d) P(cancer|smoker).

Zone 1 — Bayes' Theorem

30-Second Method

  1. Name your partition events (A₁, A₂, ... — the possible "causes" or "categories").
  2. Write down the priors P(Aᵢ) and the likelihoods P(B|Aᵢ) directly from the word problem.
  3. Compute the denominator using Law of Total Probability: \(P(B)=\sum P(A_i)P(B\mid A_i)\).

Formula 1 — Addition Law & Complement & Conditional Probability

\[P(A\cup B)=P(A)+P(B)-P(A\cap B) \qquad P(A^c)=1-P(A) \qquad P(A\mid B)=\frac{P(A\cap B)}{P(B)}\]

Symbol meanings: A, B — any two events (subsets of outcomes). ∪ — "or" (union: A happens, or B happens, or both). ∩ — "and" (intersection: both A and B happen). Aᶜ — "not A" (the complement — everything in the sample space that ISN'T in A). P(A|B) — "probability of A GIVEN B" (conditional probability — the "|" means "given that").

When to use it: Use the addition law whenever a question asks for "P(A or B)" and A, B might overlap. Use the complement rule whenever it's easier to compute "the opposite doesn't happen" than "it happens directly" (classic phrasing: "at least one," "not," "none"). Use the conditional formula whenever the question says "given that," "if it's known that," or hands you information that narrows the sample space.

Formula 2 — Addition Law for Three Events

\[P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(A\cap B)-P(B\cap C)-P(A\cap C)+P(A\cap B\cap C)\]

Symbol meanings: Same as Formula 1, extended to three events A, B, C. Every pairwise overlap gets subtracted once (to undo double-counting), then the triple overlap gets added back once (because it got subtracted three times in the pairwise step, so it needs restoring once).

When to use it: Only when a question genuinely involves THREE separate events combined with "or" — e.g. "a student struggles in Algorithms, Data Structures, or Databases." If the question only has two events, use Formula 1 instead; using the three-event formula with C=∅ (empty) is unnecessarily complicated.

Formula 3 — Bayes' Theorem (General Form)

\[P(A_m\mid B)=\frac{P(B\mid A_m)P(A_m)}{\sum_{i=1}^{n}P(B\mid A_i)P(A_i)}\]

Symbol meanings: A₁, A₂, ..., Aₙ — a full set of "categories" or "causes" that are mutually exclusive (can't both be true) and collectively exhaustive (one of them MUST be true — together they cover every possibility). Aₘ — the ONE specific category you're solving for out of that full list. B — the "evidence" or observed outcome. P(Aₘ) — the prior probability of category m (your belief BEFORE seeing the evidence). P(B|Aₘ) — the likelihood (how probable the evidence is, assuming category m is true). The denominator \(\sum_{i=1}^n P(B\mid A_i)P(A_i)\) is the Law of Total Probability — it adds up "evidence probability × prior" across EVERY possible category, giving the overall probability of seeing that evidence at all.

When to use it: Whenever a question gives you P(evidence | cause) for several possible causes, together with how common each cause is, and then asks you to REVERSE the direction — "given that we observed this evidence, what's the probability it came from cause X?" Classic signal phrases: "given that the test was positive, what's the probability the person has the disease," "given the item is defective, what's the probability it came from factory Y."

Formula 4 — Cumulative Distribution Function (single & joint)

\[F(x)=P(X\le x)=\int_{-\infty}^{x}f(x)\,dx \qquad F(x,y)=P(X\le x,Y\le y)=\int_{-\infty}^{x}\int_{-\infty}^{y}f(x,y)\,dy\,dx\]

Symbol meanings: F(x) — the CDF, "cumulative distribution function": the total probability accumulated from negative infinity up to and including x. f(x) — the PDF (density function) you're integrating. F(x,y) — the JOINT CDF for two random variables at once: the probability that X is at most x AND Y is at most y, simultaneously.

Note on discrete variables: this formula is written for CONTINUOUS X using an integral. For a DISCRETE random variable, replace the integral with a sum: \(F(x)=P(X\le x)=\sum_{x_i\le x}f(x_i)\) — same idea (accumulate probability up to x), just summing instead of integrating because discrete outcomes are separate points, not a continuum.

When to use it: Whenever a question asks for "the probability that X is at most / no more than / less than or equal to some value" — that phrasing IS the definition of the CDF. Also use it as the starting point whenever you need to derive a PDF from a given CDF (see Formula 5).

Formula 5 — Recovering the PDF from the CDF, and Interval Probability

\[f(x)=\frac{d}{dx}F(x) \qquad P(a\le X\le b)=\int_a^b f(x)\,dx\]

Symbol meanings: d/dx — the derivative with respect to x (differentiation — the reverse operation of integration). a, b — the lower and upper bounds of an interval you care about.

When to use it: Use \(f(x)=\frac{d}{dx}F(x)\) whenever a question GIVES you the CDF and asks you to find the PDF (differentiate). Use \(P(a\le X\le b)=\int_a^b f(x)dx\) whenever a question gives you a PDF directly and asks for the probability over some RANGE of values rather than a cumulative "up to x" probability.

Formula 6 — Joint PDF from Joint CDF, and Marginal PDF

\[f(x,y)=\frac{\partial^2}{\partial x\,\partial y}F(x,y) \qquad f_X(x)=\int_y f(x,y)\,dy\]

Symbol meanings: ∂²/∂x∂y — a mixed second-order PARTIAL derivative (differentiate once with respect to x, once with respect to y — order doesn't matter, the result is the same either way for continuous functions). f_X(x) — the MARGINAL density of X alone, obtained by integrating the joint density over every possible value of the OTHER variable, y.

When to use it: Use the mixed partial derivative whenever you're given a joint CDF F(x,y) and asked to find the joint PDF f(x,y). Use the marginal-density integral whenever you have a joint density f(x,y) for two variables but the question only wants the distribution of ONE of them "on its own, ignoring the other" — that's exactly what "marginal" means: collapse away the variable you don't care about by integrating it out.

Formula 7 — Conditional Probability Over a Region (Joint Distributions)

\[f_{X\mid Y}(x>a\mid y<b)=\frac{f(x>a,\,y<b)}{f(y<b)} \qquad f(x>a,y<b)=\int_{x=a}^{\infty}\int_{y=-\infty}^{b}f(x,y)\,dy\,dx\]

Symbol meanings: This is the SAME idea as ordinary conditional probability (Formula 1) — divide the joint probability by the condition's own probability — except here the condition is a whole REGION ("y is less than b") rather than one exact value ("y equals b"). a, b — the specific threshold values defining the regions x>a and y<b.

When to use it: Whenever a joint-distribution question asks something like "given that Y is less than some threshold, what's the probability X exceeds some other threshold" — i.e. the condition involves an INEQUALITY (a range), not a single point value. You compute the double-integral in the numerator over the joint region satisfying BOTH inequalities, and divide by the marginal probability of just the conditioning inequality.

Formula 8 — Mathematical Expectation

\[E(X)=\begin{cases}\sum_i x_iP(x_i) & \text{if X is discrete}\\ \int_{-\infty}^{\infty}xf(x)\,dx & \text{if X is continuous}\end{cases} \qquad E(X^2)=\begin{cases}\sum_i x_i^2P(x_i) & \text{discrete}\\ \int_{-\infty}^{\infty}x^2f(x)\,dx & \text{continuous}\end{cases}\]

Symbol meanings: E(X) — "expected value," the long-run average of X if you repeated the random experiment infinitely many times (also called the mean, μ). E(X²) — the expected value of the SQUARE of X (needed as a stepping stone to variance, Formula 9 — never skip straight to variance without this).

When to use it: Whenever a question asks for "the mean," "the expected value," "the average," or "on average, what happens" for a random variable. You always need to know whether X is discrete (use the sum) or continuous (use the integral) before choosing which version applies.

Formula 9 — Variance, Standard Deviation, Coefficient of Variation

\[V(X)=E(X^2)-[E(X)]^2 \qquad SD(X)=\sqrt{V(X)} \qquad CV(X)=\frac{SD(X)}{E(X)}\]

Symbol meanings: V(X) — variance, a measure of how spread out X's values are around the mean (bigger = more unpredictable). SD(X) — standard deviation, the square root of variance (brings the units back to the same scale as X itself, since variance is in "squared units"). CV(X) — coefficient of variation, a UNITLESS ratio comparing spread to the mean, useful for comparing riskiness across two variables measured on totally different scales.

When to use it: Use V(X) whenever asked for "the variance" or as a stepping stone toward SD or CV. Use SD(X) whenever asked for "the standard deviation" directly, or when you need actual real-world-unit spread (e.g. "±how many dollars"). Use CV(X) specifically when a question wants to compare relative variability between two different-scaled quantities (e.g. comparing the riskiness of two different investments with different average returns).

Formula 10 — Linear Transformation Rules

\[E(aX+b)=aE(X)+b \qquad V(aX+b)=a^2V(X)\]

Symbol meanings: a, b — any constants (fixed numbers, not random). aX+b — a new random variable created by scaling X by a and then shifting it by b (e.g. converting a temperature reading, or adjusting a score by a curve).

When to use it: Whenever a question changes a random variable by scaling and/or shifting it — "if every value is doubled and then increased by 3," "if we convert from Celsius to Fahrenheit," "if the instructor adds a bonus point to every score." Two critical details worth memorizing cold: the CONSTANT b disappears entirely from the variance formula (shifting everything by the same amount doesn't change how spread out it is), and the constant a gets SQUARED in the variance formula (never forget to square it — this is the single most common arithmetic slip on this formula).

Formula 11 — Binomial Distribution

\[f(x)=\binom{n}{x}p^xq^{n-x}, \quad x=0,1,\ldots,n,\ 0\le p\le1,\ q=1-p\]

Symbol meanings: n — the FIXED number of independent trials. x — the specific number of "successes" you want the probability of. p — the probability of success on any ONE trial (stays constant across all n trials). q — the probability of failure on one trial (q=1−p). \(\binom{n}{x}\) — "n choose x," the number of different orders in which x successes could occur among n trials, computed as \(\frac{n!}{x!(n-x)!}\) (where n! = n×(n−1)×...×2×1, the factorial).

When to use it: Whenever an experiment has a FIXED number of independent repeated trials, each with the same two-outcome (success/failure) structure and the same probability of success, and you want the probability of a specific TOTAL COUNT of successes. Signal phrases: "n items," "a sample of n," "each has probability p," count "exactly x," "at least x," "at most x" successes.

Formula 12 — Geometric Distribution (your faculty's exact convention)

\[f(x)=pq^x, \quad x=0,1,2,\ldots,\ 0\le p\le1,\ q=1-p\]

Symbol meanings: p — probability of success on each trial (constant). q — probability of failure (q=1−p). x — under THIS formula, x counts the number of FAILURES that occur BEFORE the first success — so x=0 means the very first trial is already a success, x=1 means one failure then a success, and so on.

⚠ Two Conventions Exist — Know Which One You're Using Some textbooks (and several of the practice problems in this vault) define X as the TRIAL NUMBER on which the first success occurs instead — giving the formula \(f(x)=pq^{x-1}\) for x=1,2,3,.... Both are the SAME distribution, just shifted by exactly 1 (trial-number X = failures-count X + 1). Your faculty's exam sheet uses the failures-count version (x=0,1,2,...) — that's the one to default to if a problem doesn't explicitly define what X counts. If a problem statement explicitly says "X = the number of trials required," use the trial-number version instead and adjust the formula to \(pq^{x-1}\). Mean also shifts accordingly: E(X)=q/p for the failures-count convention, versus E(X)=1/p for the trial-number convention.

When to use it: Whenever an experiment repeats independent identical trials (each with success probability p) UNTIL the first success happens, and you want the probability distribution of how many failures/trials that takes. Signal phrases: "the first success," "until it happens for the first time," "how many attempts before."

Formula 13 — Poisson Distribution

\[f(x)=\frac{e^{-\lambda}\lambda^x}{x!}, \quad x=0,1,2,\ldots,\ \lambda>0\]

Symbol meanings: λ (lambda) — the average number of events expected in the interval you're studying (a rate). e — Euler's number, a fixed mathematical constant ≈2.71828 (not a variable — it never changes). x! — x factorial, x×(x−1)×...×2×1 (and 0!=1 by definition).

When to use it: Whenever you're counting how many times a RARE, randomly-timed event happens within a FIXED interval of time or space, and you're given (or can compute) the AVERAGE rate. Signal phrases: "on average, N per hour/day/unit area," count of accidents, calls, defects, arrivals. Critical reminder: if the question's interval differs from the interval your given rate applies to (e.g. rate given "per day" but question asks "per week"), you MUST rescale λ proportionally before plugging into the formula.

Formula 14 — Exponential Distribution

\[f(x)=\lambda e^{-\lambda x}, \quad x>0,\ \lambda>0\]

Symbol meanings: λ — the same rate parameter as the Poisson distribution (in fact the Exponential distribution describes the WAITING TIME between Poisson events). x — a continuous measure of time (or distance) until the next event.

When to use it: Whenever a question asks about the WAITING TIME or TIME UNTIL the next occurrence of something that happens at a constant average rate — "time until the next customer arrives," "lifetime of a component," "time between phone calls." This distribution has the special "memoryless" property: how long you've already waited tells you nothing about how much longer you'll wait.

Formula 15 — Normal Distribution

\[f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac12\left(\frac{x-\mu}\sigma\right)^2}, \quad -\infty\le x\le\infty,\ -\infty\le\mu\le\infty,\ \sigma^2\ge0\]

Symbol meanings: μ (mu) — the mean, the center point of the symmetric bell curve. σ² (sigma-squared) — the variance, controlling how wide or narrow the bell is. π — pi, the familiar constant ≈3.14159. This formula describes the full, complete shape of ANY normal distribution once you know its specific μ and σ.

When to use it: You almost never plug numbers directly into this messy formula by hand — instead you STANDARDIZE using Formula 16 and read probabilities off the Z-table. This formula matters mainly for recognizing the bell-curve shape and knowing that μ and σ² are the only two things that define it.

Formula 16 — Standard Normal Distribution & Standardization

\[f(z)=\frac{1}{\sqrt{2\pi}}e^{-\frac{z^2}2}, \quad -\infty\le z\le\infty, \quad \text{where } Z=\frac{X-\mu}\sigma \text{ and } X\sim N(\mu,\sigma^2)\]

Symbol meanings: Z — the standardized score: how many standard deviations away from the mean a value X sits. Every Normal distribution, no matter its own μ and σ, can be converted into this ONE universal "standard" version with mean 0 and variance 1 — which is exactly why a single Z-table can answer probability questions for ANY normal distribution.

When to use it: This is the single most-used formula on the entire exam. Use it EVERY time you're asked for a probability involving a Normal random variable — convert X to Z first using \(Z=\frac{X-\mu}\sigma\), then look up Z in the standard normal table (see the full walkthrough further down this tab).

Formula 17 — CDF Interval & Tail Relationships

\[P(a\le X\le b)=F(b)-F(a) \qquad F(a)=P(X\le a) \qquad P(X>a)=1-P(X\le a)\]

Symbol meanings: Same F(x) as Formula 4 — the cumulative distribution function. This formula just spells out the three most common ARITHMETIC MOVES you make with a CDF: subtracting two cumulative values to get an interval probability, restating what F(a) means in probability language, and flipping a "greater than" question into "1 minus a cumulative probability."

When to use it: This is your general toolkit for ANY problem where you have (or can compute) a CDF — whether that CDF came from a Normal Z-table lookup, an Exponential formula, or any other named distribution's cumulative function. Whenever a question says "between a and b," "more than a," or "at most a," this formula tells you exactly what arithmetic to do with F.

Formula 18 — Hypothesis Testing: Z-test (known σ) AND T-test (unknown σ)

\[Z=\frac{\bar x-\mu}{\sigma/\sqrt n}\sim N(0,1) \qquad T=\frac{\bar x-\mu}{s/\sqrt n}\sim t_{n-1} \qquad s=\sqrt{\frac{\sum x_i^2-n\bar x^2}{n-1}}\]

Symbol meanings: x̄ (x-bar) — the sample mean, computed from your actual collected data. μ — the hypothesized population mean (the value in your H₀). σ — the population standard deviation, when it is KNOWN (given directly in the problem). n — sample size. σ/√n — the standard error of the mean when σ is known. s — the SAMPLE standard deviation, calculated FROM your data when the true population σ is NOT known. T — the t-statistic, used instead of Z when you must estimate σ using s. t_{n-1} — the t-distribution with "n−1 degrees of freedom" — a bell-shaped distribution similar to Normal but with slightly heavier tails, which corrects for the extra uncertainty introduced by estimating σ from a small sample rather than knowing it exactly.

Degrees of Freedom — what does "n−1" mean? When you calculate the sample standard deviation s from n data points, you first need to calculate their mean x̄ — and once x̄ is fixed, only n−1 of the n data points are still "free to vary" (the last one is forced by the requirement that they all average to x̄). This lost degree of freedom is why the t-distribution's shape depends on n−1, not n.
Which one do I use — Z or T? Look at whether the population standard deviation σ is EXPLICITLY GIVEN in the problem. If σ is given directly ("the population standard deviation is 30 minutes") → use the Z-test. If instead you're only given sample data and told to estimate spread from it, or given a sample standard deviation s directly with no population σ mentioned → use the T-test, and look up your critical value in a t-table using n−1 degrees of freedom (a separate table from the Z-table — if your exam only supplies a Z-table, that's a strong signal σ will always be given directly and the T-test likely won't be tested numerically, though you should still recognize the formula and know what it's for).

When to use it: Both are used for exactly the same PURPOSE as the rest of Lecture 19–20 (Test of Hypothesis) — testing a claim about a population mean — the only question is which formula matches what information the problem gives you about spread (a known population σ, or only a sample you have to compute s from).

How to Read & Use the Z-Table — Full Walkthrough

The Z-table you'll be given on exam day gives you the area under the standard normal curve to the LEFT of a given z-value — this is exactly \(\Phi(z)=P(Z\le z)\). Everything else you'll ever need is built from this one number using simple arithmetic.

Step-by-Step: Reading a Single Value

  1. Split your z-value into two parts: the first decimal place (row) and the second decimal place (column). For z=1.67, the row is "1.6" and the column is ".07".
  2. Find the row labeled 1.6 down the left side of the table.
  3. Move across that row to the column labeled .07.
  4. The number where they intersect IS \(\Phi(1.67)=P(Z\le1.67)\).
Worked Example — Direct Read

Find P(Z ≤ 1.67) using the Z-table.

Solution: Row "1.6", column ".07" → table gives 0.9525.

P(Z ≤ 1.67) = 0.9525
Worked Example — Negative Z

Find P(Z ≤ −1.11) using the Z-table.

Solution: Your full Z-table (uploaded) lists negative-z rows directly — no symmetry trick needed. Row "−1.1", column ".01" → table gives 0.1335.

P(Z ≤ −1.11) = 0.1335
Worked Example — Right Tail (Greater Than)

Find P(Z > 2.22).

Solution: The table only gives you the area to the LEFT. For "greater than," subtract from 1: \(P(Z>2.22)=1-\Phi(2.22)=1-0.9868=0.0132\)

P(Z > 2.22) = 0.0132
Worked Example — Between Two Values

Find P(−1.67 < Z < 1.67).

Solution: Subtract the smaller cumulative area from the larger one: \(P(-1.67<Z<1.67)=\Phi(1.67)-\Phi(-1.67)=0.9525-0.0475=0.9050\)

P(−1.67 < Z < 1.67) = 0.9050
Worked Example — Reverse Lookup (Percentile Problem)

Find the z-value such that P(Z ≤ z) = 0.90 (the 90th percentile).

Solution: This time you search INSIDE the body of the table for the value closest to 0.90, then read the row+column backwards. The closest table entries are 0.8997 (z=1.28) and 0.9015 (z=1.29) — 0.90 sits almost exactly between, so \(z\approx1.28\) (sometimes 1.282 is used for more precision).

z ≈ 1.28 (the 90th percentile of the standard normal)
Worked Example — Full Real-World Application

Heights ~ N(68, 3²). Find the height below which the shortest 30% of people fall.

Solution: Step 1 — this is a percentile problem, so search the table body for 0.30 → closest is z≈−0.52.
Step 2 — un-standardize using \(X=\mu+Z\sigma\): \(X=68+(-0.52)(3)=66.44\)

Answer: ≈ 66.44 (the height below which the shortest 30% fall)
